Match system

Follows the operating system’s light / dark preference, switching between a chosen pair.

OS light Premium Light (any light theme) OS dark Premium Dark (any dark theme)
Attributes · data-theme + data-accent on <html>; data-theme="system" resolves via prefers-color-scheme. Persistence · saved to the user profile; device copy in localStorage as fallback; inline head script applies it before first paint. Signed out · patient app and public pages follow the system setting. Transition · 260ms colour cross-fade; instant under reduced motion. Video room · always the dark call stage, whatever the theme.
